# Skill bundle

Curated subset shipped with AIGON PROOF: **53 skills in 5 categories**.

Each directory holds a `SKILL.md` with YAML frontmatter (`name`, `description`) and, where
useful, `references/`, `scripts/` and `templates/`. The governance explorer exposes the same
bundle through the `skills_list`, `skills_by_category` and `skills_get` tools.

## How the graph is wired

Nodes are **law**, **gate**, **category** and **backend**. Edges are `gate -> category`
(module keyword classification) and `law -> gate` (shared significant terms). A skill is
reached through its category node and through the catalogue, so it needs no separate edge
to be reachable.

This bundle is a **curated subset**. Names of internal-only skills are either replaced by the
closest shipped skill or explicitly marked as outside the bundle. `scripts/check_skills.py`
fails the build if frontmatter is invalid, a name repeats, a relative link is dead, or an
explicit reference points at a skill that is not shipped.
