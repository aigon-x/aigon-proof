# Release scope

This clean public repository contains the tested AIGON PROOF v2 source, curated fixtures, skill/gate bundle, judge instructions and current demonstration. Private development history, operator credentials, application state, recorded local browser sessions and unrelated old video assets are excluded.

Required features: typed actions; server-owned policy metadata; operator authentication; exact-action consent; denial/revocation; expiring signed passport; local document delivery; fsync/read-back receipt; restart-safe single execution; API/MCP and responsive UI.
